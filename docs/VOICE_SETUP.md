# Clear voice setup — 0.1.2

1. Install the 0.1.2 APK from dev-4.
2. Open **Google voice • install / update** to visit the official Google Speech Recognition & Synthesis listing if you need an engine: https://play.google.com/store/apps/details?id=com.google.android.tts
3. Return to Hermes Bridge. Tap **Refresh engines & voices** and **Choose speech engine**. Select Google's engine if available, or another installed engine you prefer.
4. Select **বাংলা** for Bengali preview or English for English preview.
5. If no usable voice appears, tap **Install voice data** for the selected engine. Install Bengali data if offered. Some engines may instead open system Settings; find Text-to-speech and its voice-data settings. Return and refresh.
6. Tap **Choose voice**. Try available voices one at a time with **Test selected voice**. Labels show locale and Offline/Online; Voice numbers are local list positions, not stable identity or a quality guarantee.
7. Retain the speed you prefer. Neutral pitch 1.0 is applied automatically. Voice settings are private to this app.
8. Online voices are excluded by default. Enable them only if you want to try engine-provided online synthesis; this can send text to that provider and requires a working connection. No cloud API key, subscription or voice model is bundled with this app.
9. Close/reopen the app and verify engine, language, voice and speed persist.

Engine voices vary in pronunciation and naturalness. The app cannot turn a low-quality installed voice into a human recording. Bengali (Bangladesh) voices are ranked before other Bengali locales when available, then sorted using the engine's declared quality. Preview and choose by listening.

Report engine label, language/voice label, speed, audible clarity and whether settings persist.
If Android rejects a debug APK update because the certificate changed, uninstall only Hermes Bridge, install the new APK and enable Accessibility normally again. Do not remove Termux, Telegram or existing Hermes data.
